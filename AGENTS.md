# AGENTS.md

Instructions for AI coding agents (and humans) working on this repository. Read [README.md](README.md) first for the overview, site map and content model; this file covers the rules and gotchas.

## Project in one paragraph

Trilingual (Basque `eu` = default, Spanish `es`, English `en`, each in its own folder: `/eu/`, `/es/`, `/en/`, with `/` redirecting to `/eu/`) static site for Euskelec, the Basque vocational training electric vehicle championship, replacing the old WordPress site at `euskelec.eus`. Built with **Hugo ≥ 0.146 (extended)** and **Tailwind CSS v4 via npm**, using a custom theme in `themes/euskelec`. It deploys to GitHub Pages through `.github/workflows/pages.yml` on every push to `main`. It shares its technology with the `cyberlehia` and `basqueunevocweek` sites, not their design or content: keep them separate.

## Commands

```sh
npm ci                                   # once: installs Tailwind (required by Hugo)
hugo server --baseURL http://localhost:1313/euskelec/   # dev server on http://localhost:1313/euskelec/eu/, the same path as GitHub Pages
hugo --gc --minify -d /tmp/check          # production build check; never into public/ while `hugo server` runs (it serves public/ and would show the production HTML, without the /euskelec/ prefix and without styles)
hugo --gc --minify --baseURL https://tknika.github.io/euskelec/ -d /tmp/out   # test a subpath build
```

There is no test suite. **A change is verified when:**
1. `hugo --gc --minify -d /tmp/check` finishes with no `ERROR` and no `WARN` lines.
2. A build with a subpath `baseURL` (command above) has no links that miss the prefix:
   `grep -rhoE '(href|src|poster)="?/[^" >]*' /tmp/out --include=*.html | grep -vE '="?/euskelec/'` prints nothing.
3. For visual changes, check the pages at ~1440px and ~390px wide, in the three languages.

## Hard rules

1. **Three languages, always.** Every content change in one of `content/eu/`, `content/es/`, `content/en/` needs the matching change in the other two, with the same `translationKey`. Every new UI string goes in `themes/euskelec/i18n/eu.yaml`, `es.yaml` and `en.yaml`; never hardcode texts in layouts.
2. **Keep the old URLs.** The slugs match the old WordPress site (`/eu/lehiaketa/`, `/es/competicion/`, `/en/competition/`, the legal pages…). Don't rename them; if one must change, add an `aliases:` entry.
3. **Never hardcode URLs** in templates: use `.RelPermalink`, `relURL`, `relLangURL` or `absURL`, and pass asset paths without a leading `/` (`images/x.jpg`). In CSS, reference `static/` files with relative URLs (`../fonts/…`). In Markdown, write internal links as `/path/` without the language prefix: `_markup/render-link.html` turns pages into `relLangURL` and files into `relURL`.
4. **Don't invent facts.** Dates, venues, rules, results and sponsors come from the organisers. While a fact is unknown, leave the field empty (it shows "Laster" / "Próximamente" / "Coming soon") or use a `{{< note >}}`, and say so in your summary.
5. **Tailwind: npm only.** Hugo 0.16x refuses the standalone `tailwindcss` binary. No PostCSS, `tailwind.config.js` or extra npm packages unless asked (`three` and `leaflet` were asked for); Tailwind v4 is configured in CSS (`@theme` in `assets/css/main.css`).
6. **Don't commit build output:** `public/`, `resources/_gen/`, `node_modules/`, `hugo_stats.json` and `.hugo_build.lock` are git-ignored. `_originals/` (full-size photos and old-site downloads) too.
7. **Keep it static and light.** No tracking scripts, no new third-party requests. Fonts are self-hosted. YouTube is only contacted when a video tile is clicked (youtube-nocookie). The contact page map loads OpenStreetMap tiles (`tile.openstreetmap.org`, which sets no cookies; keep the "© OpenStreetMap" attribution): never Google Maps or another map that sets cookies, as asked (2026-11). The only JavaScript is that click handler, the pause button of the home video (which also stops autoplay under `prefers-reduced-motion`) and the photo lightbox of `{{< gallery >}}`, in `main.js`, the 3D car of the competition page (below), and the contact map (`assets/js/map.js`, Leaflet, loaded only there); the mobile menu is a `<details>`. Photos of the car and the competition must be real; the only 3D models are the teams' own car models, given by the organisers (2026-11), never models or illustrations made up for the site.

## Conventions

- **Template layout (Hugo ≥ 0.146):** `layouts/baseof.html`, `home.html`, `page.html`, `404.html`, with `_partials/`, `_shortcodes/` and `_markup/`. Don't create `_default/` or `partials/`.
- **Languages:** `languages.<lang>.contentDir` in `hugo.toml`, `defaultContentLanguageInSubdir = true`. Translations are matched by `translationKey`; `partial "by-key.html" "competition"` returns the page with that key in the current language.
- **Menus** come from front matter (`menus: main` / `footer`). *Formakuntza / Formación / Training* was a link to the YouTube playlist (in `hugo.toml`) until November 2026; it is now the training page.
- **Competition page:** no long paragraphs; the overview is `intro` in its front matter (steps, goals, platform), drawn by `{{< competition-intro >}}`. Phases can have `challenges` (chips) and a `note`.
- **Phases** live in the competition page front matter and are shown there and on the home page. The dynamic tests belong to **phase 2 only**: a `tests` list inside that phase, drawn in its card with inline line SVGs (`static/images/icons/`, `currentColor`). Never show them as a block of the whole competition.
- **Media = press room** (title kept as "Media"): press contact, press kit (3 PDFs), poster, videos and photos. The organisers' logos to download were removed in November 2026, as asked; the official files and where they came from are kept outside the site, in `_originals/press-logos/` (git-ignored; also in the git history).
- **Press kit:** `content/<lang>/{prentsa-dossierra,dossier-de-prensa,press-kit}.md` with `layout: dossier` (`layouts/dossier.html`, four A4 pages, not listed anywhere). It takes every text from the site (home, competition page, `hugo.toml`, `data/participants.yaml`); its front matter only has labels. The cover names the document (the page title: Prentsa-dossierra, Dossier de prensa, Press kit) in a lime label beside the logo. Page backgrounds are utilities (bg-brand, bg-paper): `.dossier-page` keeps its white in the components layer so they win (until November 2026 it did not, and the cover and the organisers' box printed white). Sponsors are left out until the list is confirmed. After changing those texts, regenerate the PDFs with `scripts/build-dossier.sh` (dev server running; Chrome or Edge headless, driven by `scripts/print-pdf.mjs` over the DevTools protocol: Chrome's `--print-to-pdf` flag stopped writing the file on Windows; Node 22+) and commit `static/docs/euskelec-{prentsa-dossierra,dossier-de-prensa,press-kit}.pdf`.
- **Technical documentation page:** `layout: technical-docs` (`layouts/technical-docs.html`). Its front matter holds the two PDFs (`documents`: rules and challenges, as download cards) and a summary of them: the challenge calendar (`calendar`, one row per task with its months), the scoring system (`scoring`; the phase totals are added up from the parts) and the vehicle (`vehicle`: the rules' dimension drawing, the critical dimensions and the powertrain kit). Every name and figure is copied from the PDFs (X edition, ref. 9-2026): when new PDFs arrive, update the three languages, including `pages` (the size is read from the file). `static/images/docs/vehicle-dimensions.jpg` is Ilustración 1 of the rules, cut from the PDF page.
- **404:** each language gets its own `404.html`; CI copies `public/eu/404.html` to `public/404.html` for GitHub Pages.
- Deprecated APIs to avoid (Hugo 0.158+): `languageName`, `.Language.LanguageName`, `.Language.LanguageCode`. `templates.Defer` (in `_partials/css.html`) must be called through `partial`, never `partialCached`.

## Design

- **Palette given by the organisers (2026-11), light theme:**
  - The Euskelec blue `brand` #397FAD is the main colour: the logo, the video tint, the page headers, the test tiles, the call to action. The footer uses the deeper `brand-800`.
  - Text is the dark grey `ink` #333333 on white. Secondary text uses `ink-soft`, borders `line`, and light grey sections `paper`.
  - The Tknika lime `tknika` #BED23B is only for touches: eyebrow lines, list bullets, the active menu item and phase, the accent button (`btn-accent`, used on blue or on the video), the video play buttons, and **every hover** (button backgrounds, card borders, menu and link underlines, footer links). Never use it for text on white: its contrast is too low.
  - White on `brand` is only 4.4:1, so on `brand` write white text only when it is large (≥24px, or ≥18.7px bold). Small white text goes on `brand-700` or darker. Links and small blue text on white use `brand-700`. (Bold means 700: semibold 600 does not count, so the competition goals box, the home call to action and the press kit's blue blocks are on `brand-700` since November 2026.)
  - Accessibility review (November 2026, axe-core + manual): the focus ring is `brand-700`, but white inside `footer` and `bg-brand*` blocks, and `--hdr-fg` in the home header (white over the video, ink once it turns white). `hero-shade` darkens the top of the video (brand-900 85% → 80% under the header, gone at 11rem) so the white header text keeps ≥4.5:1 on every frame: measure again if the video changes.
  - Square corners (no `rounded-*`).
- Font: Lexend (`font-display`, self-hosted variable font) for titles, menus and labels; system sans for running text.
- The logo is redrawn as one SVG in `_partials/logo.html`, traced from the old site's 218×25 PNG (`_originals/old-site/euskelec_logo.png`): five white bars in two staggered columns and the wide EUSKELEC lettering, all white (no blue, no Lexend). It is 1em high, so the parent's font size sets its size. Replace it with the official vector logo when available.
- **The symbol** (five bars in two staggered columns, as in the logo and the favicon) is the site's graphic resource: `{{ partial "symbol.html" "classes" }}` draws it as an SVG in `currentColor`, sized and placed with the classes. It is used large and faint on the blue page headers and the footer, small on the home section cards (lime on hover), in the corner of each phase (lime when active) and on the 404 page. Keep it as a solid shape, cut by the edges when big; don't rotate or recolour it outside the palette.
- **Widths, as on basqueunevocweek:** the home page, the header and the home footer use `container-wide` (the whole window, side margins only); inner pages use `container-site` (up to 96rem), with text kept to a readable column (`max-w-3xl`, unless `wide: true`).
- **3D car (competition page):** `intro.model` in the three competition pages (`src`, a `.glb` in `static/models/`; `still`, a picture of the same model in `static/images/`) puts the car beside the lead, turning slowly on itself; without it, the home photo shows. Drawn by `assets/js/car3d.js` with **three.js** (npm `three`, bundled by Hugo's `js.Build` as an ES module: DRACOLoader needs `import.meta.url`, so keep `"format" "esm"` and `type="module"`), loaded only on that page. The models given by the organisers (in `_originals/3d/`, not committed: `EUSK26_MenDiTech_web.glb`, `HernanaiGB_web.glb`, `euskelec_aic_web.glb`) are Draco-compressed with WebP textures; the Draco decoder is served from `static/vendor/draco/` (copied from `node_modules/three/examples/jsm/libs/draco/gltf/`; copy it again after updating three). The four wheels are one mesh, so the whole car turns, not the wheels. A pause button (WCAG 2.2.2) and `prefers-reduced-motion` stop it; it only draws while on screen. If the model or the start angle (`START` in `car3d.js`) changes, make a new `still`: the page with reduced motion shows the model stopped at the start angle; capture the stage at 2× (1224×918).
- **Car on the home** (`hero_image` in the home front matter, `static/images/bolido-side.svg`, November 2026, replacing `bolido.png`): the organisers' CAD side view of the car, redrawn as an SVG on the picture's own coordinates (1885×1005), so sizes and positions are the drawing's: tubes, wheels, motor, battery, inverter, steering and floor in vector; the driver cut out of the picture, in grey, embedded as a PNG. Background, labels (MOTOR, BATERÍA, INVERSOR), arrows and CAD marks removed; colours unified (structure in the brand blue with a light edge for volume, mechanical parts in graphite and steel, lime touches) and a soft shadow on the ground. The thin light line over the car is the drawing's top line and nose. Its width and height in `home.html` are the picture's proportions. Sources to edit it (the SVG with the driver apart, the CAD picture, the cut-out code) in `_originals/car-side/`, not in git.
- **Countdown** (header, thin bar left of the languages; `_partials/countdown.html`, main.js): to `countdown` in hugo.toml, the start of phase 2 with its time zone (16 May 2027, 18:00, asked in November 2026; first set to 12:00, corrected the same day). The same date is written by hand in phase 2's `dates` (`place`: Vitoria-Gasteiz) in the three competition pages, shown on the home, the competition page and the press kit: change them together, and print the press kit again. main.js counts from the visitor's clock: days and hh:mm:ss every second; days, h and min every minute for reduced motion. On phones only a chequered flag and the time (the words are for screen readers). Hidden without JavaScript, gone once the date has passed (and left out of builds after it): set the next date then. Words in i18n (`countdown`, with %s for the time; `countdownDays`; `countdownDate`, a Go layout whose month Hugo translates).
- **Home video:** `hero_video` in the home front matter (`large` 1920px, `small` 960px for phones, `poster`), files in `static/video/`. Muted, looping, no audio track, under a transparent header (`.header-home`: white text over the video, white with ink text once the page scrolls, through a CSS scroll-driven animation of the registered `--hdr-fg` / `--hdr-logo` colours). The source is `_originals/videos/home.mov`. It is used as it is, with straight cuts (symbol transitions at some cuts were tried in 2026-11 and dropped; `scripts/video-symbol-transitions.sh` can still render them). Encode with `ffmpeg -i home.mov -an -c:v libx264 -preset slow -crf 30 -pix_fmt yuv420p -movflags +faststart -vf scale=1920:-2 home-vN-1920.mp4` (crf 28 and `scale=960:-2` for the small one). Nothing is drawn over the video in the page itself. Keep the video short and under ~5 MB. When the video changes, give the files a new name (`home-v4-…` → `home-v5-…`, in the three `_index.md`): browsers keep the old file cached under the same name.
- Components in `@layer components` in `main.css`: `container-site`, `container-wide`, `site-header`, `header-home`, `hero-shade`, `btn-primary`, `btn-accent`, `btn-ghost`, `btn-ghost-light`, `eyebrow` (+ `eyebrow-light`), `card`, `bars-bg` (stripes, only behind the home call to action), `prose-site`. In Tailwind v4 you can't `@apply` a custom component class.
- **Training page** (`content/<lang>/{formakuntza,formacion,training}.md`, asked in November 2026): the training videos by topic, in six `{{< videos >}}` blocks (getting started; design and ergonomics; electric vehicle technology; project, innovation and communication; talks; full training days), 18 per language. Picked from the Euskelec videos on Tknika's channel (@tknkanala): its "Euskelec" playlist (the old menu link) mixes training, summaries and races, and misses the IV training series (01-06, January 2021) and the full training days; the summaries and races are in Media, the training videos only here. Each line: ID | title written for the page | year | edition and length (the 4th field of the shortcode, a small line under the title). The VI training day was uploaded twice (Spanish and Basque titles, same date and length): one per language. The videos are from editions IV-VIII: the organisers should confirm which are still valid under the current rules, and the spoken language of each was not checked. The YouTube link of the contact page is now "Euskelec videos" (it said training videos).
- **Video preview images** (`static/images/videos/<ID>.jpg`, 640×360, about 30 KB): `scripts/fetch-video-thumbs.sh` (needs ffmpeg). Without ffmpeg (November 2026), the same crop was made with .NET System.Drawing (JPEG q78). When YouTube's picture is a black frame, use one of its automatic frames instead (`hq1.jpg`, `hq2.jpg`, `hq3.jpg`), as for `xm6x8g7H6Ok`.
- **Photos and videos (Media):** Media is a section (`content/<lang>/media/_index.md`, template `section.html`) so it stays light: the newest videos big (`{{< videos featured="2" more="…" >}}`, the rest smaller: every edition's summary, with the short versions, the San Mamés Grand Prix, the 2021 phase 1 and the project presentation, the 2021 summary and the project in the page's language), then the full race broadcasts (`### Full broadcasts`, with their length; the VI race was uploaded twice, 2 h 36 min and 47 min) and the photos as album cards (`{{< albums >}}`). Each album is a page under `media/` with `layout: album` (`album.html`): `title`, `eyebrow`, `description`, `weight` (order), `cover`, an optional `video` (`src`, `alt`) and `photos` (`src`, `alt`; the alt text is also the lightbox caption; the 2018/2019 photos got theirs in November 2026). Same albums, same order in the three languages (`translationKey: album-…`). Photos about 1600 px on the long edge (JPEG q80), plus a `thumbs/` folder beside them with 4:3-covering 640×480 thumbnails (q74) that the grids and cards use automatically (`_partials/thumb.html`); originals in `_originals/photos/<year>/`. The 2026 photos have neutral file names (no people's names in URLs) and alt texts that describe what is seen without naming or gendering anyone. Every photo opens in the lightbox (`_partials/lightbox.html`, added by `baseof.html` to album pages and to pages using `{{< gallery >}}`; arrows, swipe, Esc; without JS the link opens the image). Videos in an album: no autoplay, `preload="none"`, H.264 ≤1280 px, no sound track if it has none to say.
- Markdown output is wrapped in `.prose-site`; add `not-prose` to custom lists inside it (shortcodes do).
- Tailwind only sees classes present in `hugo_stats.json` or the CSS: write full class names, never build them with `printf`. In the dev server, CSS changes may need a server restart (the file keeps its name).
